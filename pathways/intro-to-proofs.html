Intro to proofs study pathway

Pathway · Educational only · Updated 22 Sep 2026

Proofs are explanations that compel agreement from a skeptical but fair reader. This pathway builds that habit inside calculus statements, instead of dumping a symbolic logic course on you at once. It orders the analysis topic, explainers, glossary entries, two calculators used only as pictures, and the sources list.

Who this pathway is for

Start here if a proof course is in front of you, or if your calculus so far was mostly computation. You might compute derivatives easily and freeze when a definition says “for every epsilon there exists a delta.” That freeze is the audience.

Each checkpoint asks you to write and then rewrite. Reading the page is not the step.

Prerequisites

You need algebra, function notation, and the willingness to define a word before you use it. The examples are limits, continuity, and series. If limits are new, read calculus foundations in parallel.

This is not a formal logic course. You will meet “for every” and “there exists” in the order a limit uses them. If derivative language is rusty, repair it with what a derivative actually measures on the AP Calculus AB bridge, then come back.

What you will be able to do

When you finish the checkpoints, you should be able to do the following with a short statement, not with a chapter.

  • Unpack a definition into quantifiers before any algebra.
  • Write an epsilon delta proof that $\lim_{x\to 2}(4x-1)=7$, in the forward direction.
  • Explain why the sum of two functions that are continuous at a point is continuous at that point, using a split of the tolerance.
  • State, as an outline, why a bounded monotone sequence of real numbers converges, without inventing a construction of the reals.
  • Tell a sequence from a series, and name a convergence test together with the hypothesis it needs.
  • Keep one counterexample that kills a false converse, and end a write up by naming what was proved.

Suggested order

Work in this order. Scratch work may run backward from the goal. The write up you keep runs forward.

  1. Read real analysis and proof habits. Unpack definitions, separate scratch work from the written proof, name quantifiers, and use a counterexample when a universal claim is false.
  2. Read the short forms: limit, epsilon delta, continuity, sequence, convergence, partial sum, and series. Stay here until you can say which word is a list and which word is a sum of that list.
  3. Read epsilon delta intuition without terror. Open the numerical limit estimator only as a picture. Its default example is a hole you can fill: samples approach a number while the function may be undefined at the point. That is allowed for a limit. It is not a proof. The FAQ on calculators versus understanding says the same thing.
  4. Write three proofs of increasing ambition. Details are below. (a) $\lim_{x\to 2}(4x-1)=7$. (b) The sum of two functions continuous at a point is continuous there. (c) A bounded monotone sequence converges. An outline is enough for (c) on the first pass.
  5. Read sequences, series, and when infinite sums make sense. Partial sums are the meaning of infinite addition. Use the arithmetic and geometric sequence calculator only for a finite sum. A finite total is not a convergence verdict.
  6. Read convergence tests for series without fog, with the comparison test, the ratio test, and the root test. For each test, write the hypothesis and the case where it stays silent.
  7. For a full textbook treatment, use the sources page, including MIT OpenCourseWare. This pathway is three checkpoints and a set of habits. It is not that course.

Checkpoints and practice habits

Keep a polished column and a counterexample column. Scratch can be messy. The polished column cannot.

Tone. A final write up defines terms, states assumptions, and ends by naming what was proved. If the last sentence does not say what you established, the argument is not finished, even if the algebra was correct.

Proof (a). Claim: $\lim_{x\to 2}(4x-1)=7$. Let $\varepsilon>0$. Then $|(4x-1)-7|=4|x-2|$. Choose $\delta=\varepsilon/4$. If $0<|x-2|<\delta$, then $4|x-2|<\varepsilon$. Write it in that order. One window is enough. A smaller positive window also works.

Proof (b). Assume $f$ and $g$ are continuous at $a$, and show $f+g$ is too. You need $|(f+g)(x)-(f+g)(a)|$ small when $x$ is near $a$. The triangle inequality splits that into $|f(x)-f(a)|+|g(x)-g(a)|$. Given $\varepsilon>0$, take a window where $f$ stays within $\varepsilon/2$ and a window where $g$ stays within $\varepsilon/2$. The smaller window makes the sum of those pieces less than $\varepsilon$. End by naming continuity of the sum at $a$.

Proof (c), outline only. A bounded monotone sequence of real numbers converges. For an increasing sequence bounded above, let $L$ be the least upper bound of the set of terms. $L$ is an upper bound, and no smaller number is, so terms must eventually sit close to $L$. Do not invent a construction of the real numbers. An honest outline is enough. The full argument belongs to a book on the sources page.

Counterexample. “If $a_n$ tends to $0$, then the series converges” is false. The terms $1/n$ tend to $0$, and the harmonic series diverges. The other arrow is true: convergence of a series forces the terms to $0$. Sequences, series, and when infinite sums make sense keeps those apart.

Quantifier swap. “For every $\varepsilon>0$ there exists a $\delta>0$” is not “there exists a $\delta$ that works for every $\varepsilon$.” The limit definition lets you choose the window after the tolerance is named.

Common pitfalls for self learners

Pitfall. Finding one delta that works for a single epsilon does not finish a proof. A table of nearby values does not finish it either. You need a rule that produces a valid delta for an arbitrary positive epsilon. The numerical limit estimator is allowed in the scratch column. It is not allowed as the last line of the polished column.

Scratch may start from the desired inequality. The kept argument starts with “let epsilon be positive.” Proving the converse is a quiet failure, and a silent ratio test (limit of absolute ratios equal to $1$) is not convergence. Convergence tests for series without fog tells you to switch tests. “Clearly” is not a step.

Common questions

Do I need a logic textbook before I start?

No. This pathway practices quantifiers inside calculus statements. A symbolic logic course can come later if you want it. You do need algebra and the patience to rewrite.

Are the three sample proofs a complete analysis course?

No. They are checkpoints. A full course covers completeness, continuity on intervals, differentiation theorems, and more. Use the sources page for open textbooks and courseware when you want that treatment.

Can I use the limit estimator inside a proof?

Only as scratch intuition. A table can support a guess and can catch a jump. A proof needs a rule that produces a valid delta for an arbitrary epsilon. The calculator does not choose that rule.

What if I get stuck on the monotone sequence outline?

Stop at the statement. A bounded monotone sequence of real numbers converges. For an increasing sequence that is bounded above, the least upper bound of the set of terms is the limit. Name that idea in words. Do not invent a construction of the real numbers. Return after the sequences explainer if the words still feel loose.

Which pathway should I open next?

If the next class is linear algebra with proofs, use the linear algebra first course for pictures, then prove a small fact in the same write up style. If computational calculus still needs repair, use the AP Calculus AB bridge and come back when a definition asks for quantifiers.
