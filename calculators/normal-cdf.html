Bell curve tails

Normal CDF and z score calculator

Calculator · Runs offline in your browser · Educational only · Updated 18 Sep 2026

This page offers two standard normal tools. In CDF mode it approximates $\Phi(z)=P(Z\le z)$ for $Z\sim N(0,1)$. In inverse mode it returns a $z$ whose left tail probability matches a percentile you type.

The output is meaningful when a normal model is already justified, and when you want a left tail probability or a $z$ cutoff. Many school tables stop at two decimals. This page is a smoother table, not a reason to assume normality.

This is not a certified statistics library and not a proof. CDF uses an error function approximation from Abramowitz and Stegun (formula 7.1.26) via $\Phi(z)=\tfrac12(1+\mathrm{erf}(z/\sqrt{2}))$. The inverse uses a rational approximation in the style of Acklam and Beasley Springer. Treat the digits as educational, not as a regulatory compute.

For inverse mode, values above 1 are treated as percentages (97.5 → 0.975).

How to use the two modes

For $\Phi(z)$, leave the menu on CDF, type a $z$ score, and press Compute. The default $z=1.96$ should land near $0.975$, the familiar two sided $95\%$ cutoff from the left.

For a $z$ from a percentile, switch to inverse mode. Values above $1$ are treated as percentages, so $97.5$ means $0.975$. Values already in $(0,1)$ are treated as probabilities. The default $97.5$ should return a $z$ near $1.96$.

How to read the output

$\Phi(z)$ is a left tail. It is the chance that a standard normal is at most $z$. It is not a two sided $p$ value, and it is not $P(Z>z)$ unless you form $1-\Phi(z)$ yourself.

The inverse answers “which $z$ has this left tail?”. If your course talks about a right tail cutoff, convert first. A right tail of $5\%$ is a left tail of $95\%$, not $5\%$.

To move from a general $N(\mu,\sigma^2)$ value $x$ to a $z$, compute $z=(x-\mu)/\sigma$ by hand, then use this page. The page does not store $\mu$ or $\sigma$.

Common pitfalls

Accuracy is weaker far in the tails than near the mean. Do not use this page for extreme quantiles in a high stakes setting. A statistical package with a well tested library belongs there.

Percentiles and probabilities use the same box in inverse mode. Typing $0.975$ and typing $97.5$ are meant to agree. Typing $97.5$ in CDF mode as if it were a $z$ will not do what you wanted.

A normal curve is a model. Data that are skewed, discrete, or bounded can make a $z$ score a poor summary even when the arithmetic is fine.

Common questions

Is Phi(z) a two sided probability?

No. It is the left tail P(Z is at most z). A two sided 95 percent interval uses both tails. People often want 1 minus Phi(z) for a right tail.

Should I type 97.5 or 0.975 in inverse mode?

Either. A value above 1 is treated as a percentage. A value already between 0 and 1 is treated as a probability. Both 97.5 and 0.975 ask for the same z.

How do I handle a normal that is not standard?

Convert x to a z score by subtracting the mean and dividing by the standard deviation, then use this page. The page itself only knows the standard normal.

How accurate is the approximation?

Near the center it is plenty for homework. Far in the tails the documented error bound is small but not zero, and this is still not a certified library. Use a statistics package when a decision is high stakes.
