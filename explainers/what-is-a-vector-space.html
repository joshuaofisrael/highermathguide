What is a vector space?

By the Higher Math Guide editorial team. Last reviewed: 13 November 2026.

Explainer · Linear algebra · Educational only · Updated 13 Nov 2026

A vector space is a set of objects you can add together and multiply by numbers, where those two operations follow the familiar rules of arithmetic. The objects are called vectors, and the numbers are called scalars. Arrows in the plane are the first example, but polynomials, matrices, functions and the solution sets of homogeneous linear systems are vector spaces too. The point of the definition is to prove facts about linear combinations once and then use them in every one of those settings.

Without the fog

Jim Hefferon's free textbook Linear Algebra opens its chapter on vector spaces with exactly this motive. Results about linear combinations should apply anywhere linear combinations make sense, not only to columns of numbers. Any setting where they make sense gets the name vector space, so a theorem can say "in any vector space" instead of being proved again for each case.

So when you meet the definition, read it as a checklist that says: adding and scaling are always possible inside the set, and they behave the way adding and scaling numbers behave.

The definition

Hefferon's Definition 1.1 says a vector space over $\mathbb{R}$ is a set $V$ with an addition and a scalar multiplication such that, for all vectors $\mathbf{u}, \mathbf{v}, \mathbf{w}$ in $V$ and all real scalars $r, s$:

  1. Closed under addition: $\mathbf{v} + \mathbf{w}$ is in $V$.
  2. Addition is commutative: $\mathbf{v} + \mathbf{w} = \mathbf{w} + \mathbf{v}$.
  3. Addition is associative: $(\mathbf{v} + \mathbf{w}) + \mathbf{u} = \mathbf{v} + (\mathbf{w} + \mathbf{u})$.
  4. Zero vector: there is a $\mathbf{0}$ in $V$ with $\mathbf{v} + \mathbf{0} = \mathbf{v}$ for every $\mathbf{v}$.
  5. Additive inverses: each $\mathbf{v}$ has a $\mathbf{w}$ in $V$ with $\mathbf{w} + \mathbf{v} = \mathbf{0}$.
  6. Closed under scalar multiplication: $r\mathbf{v}$ is in $V$.
  7. $(r + s)\mathbf{v} = r\mathbf{v} + s\mathbf{v}$.
  8. $r(\mathbf{v} + \mathbf{w}) = r\mathbf{v} + r\mathbf{w}$.
  9. $(rs)\mathbf{v} = r(s\mathbf{v})$.
  10. $1\mathbf{v} = \mathbf{v}$.

Hefferon singles out the two closure conditions, 1 and 6, as especially important. They say the operations always make sense: every sum and every scalar multiple stays inside the set. In practice, closure is where most candidate sets fail.

Examples you already know

  • $\mathbb{R}^n$. Columns of $n$ real numbers, added and scaled entry by entry.
  • A line through the origin. Hefferon's first worked example is the line $y = 3x$ in $\mathbb{R}^2$. Adding two points on the line, or scaling one, lands back on the line.
  • Polynomials of degree at most 3. $\mathcal{P}_3 = \{a_0 + a_1x + a_2x^2 + a_3x^3\}$ with the usual polynomial addition and scaling. For instance $$3(1 - 2x + 3x^2 - 4x^3) - 2\left(2 - 3x + x^2 - \tfrac{1}{2}x^3\right) = -1 + 7x^2 - 11x^3.$$
  • Matrices. The 2 by 2 real matrices, added and scaled entry by entry.
  • Functions. All real valued functions of a real variable, with $(f + g)(x) = f(x) + g(x)$ and $(rf)(x) = rf(x)$.
  • Solution sets. The solutions of a homogeneous linear system $A\mathbf{x} = \mathbf{0}$, and the solutions of the differential equation $f'' + f = 0$, are vector spaces under the same operations.

Hefferon also notes that $\mathcal{P}_3$ is not a subset of any $\mathbb{R}^n$, yet it behaves like $\mathbb{R}^4$: match $a_0 + a_1x + a_2x^2 + a_3x^3$ with the column $(a_0, a_1, a_2, a_3)$ and the operations line up. That is the payoff of the abstraction. Once you can compute in $\mathbb{R}^4$, you can compute with cubic polynomials.

Subspaces: the test you will actually use

Most sets you are asked about sit inside a space you already know is a vector space, such as $\mathbb{R}^n$. Then you do not need all ten conditions. Margalit and Rabinoff's Interactive Linear Algebra defines a subspace of $\mathbb{R}^n$ as a subset $V$ with three properties:

  • Non emptiness: the zero vector is in $V$.
  • Closure under addition: if $\mathbf{u}$ and $\mathbf{v}$ are in $V$, so is $\mathbf{u} + \mathbf{v}$.
  • Closure under scalar multiplication: if $\mathbf{v}$ is in $V$ and $c$ is a real number, $c\mathbf{v}$ is in $V$.

Hefferon's Lemma 2.9 packs this into one line for any vector space: a nonempty subset is a subspace exactly when it is closed under linear combinations. The other rules, such as commutativity, are inherited from the bigger space for free.

Interactive Linear Algebra adds a useful fact: every span is a subspace, and every subspace of $\mathbb{R}^n$ is the span of some linearly independent vectors. So "subspace" and "span" describe the same objects. Two subspaces you will meet constantly are the column space and the null space of a matrix.

Worked example 1: a plane through the origin

Is $V = \{(x, y, z) : x + 3y + z = 0\}$ a subspace of $\mathbb{R}^3$?

  • Zero: $0 + 3 \cdot 0 + 0 = 0$, so $\mathbf{0}$ is in $V$.
  • Addition: if $x_1 + 3y_1 + z_1 = 0$ and $x_2 + 3y_2 + z_2 = 0$, adding gives $(x_1 + x_2) + 3(y_1 + y_2) + (z_1 + z_2) = 0$, so the sum is in $V$.
  • Scaling: multiplying $x + 3y + z = 0$ by $c$ gives $cx + 3(cy) + cz = 0$, so $c\mathbf{v}$ is in $V$.

So $V$ is a subspace. Solving for $x = -3y - z$ shows it is a span: $$V = \operatorname{Span}\{(-3, 1, 0),\ (-1, 0, 1)\}.$$ Check both: $-3 + 3 + 0 = 0$ and $-1 + 0 + 1 = 0$. The same argument works for the solution set of any homogeneous system, which is why null spaces are always subspaces.

Worked example 2: sets that fail

Interactive Linear Algebra lists standard non examples in $\mathbb{R}^2$. Each fails a specific condition.

  • A line that misses the origin, such as $y = 3x + 1$. The zero vector is not on it, so it fails at the first check. (Also, $(0,1)$ and $(1,4)$ are on it but their sum $(1,5)$ is not.)
  • The first quadrant, points with $x \ge 0$ and $y \ge 0$. It contains zero and is closed under addition, but $(1,1)$ times $-1$ is $(-1,-1)$, which is outside. Closure under scalar multiplication fails.
  • The unit circle $x^2 + y^2 = 1$. It does not contain zero, and $(1,0) + (0,1) = (1,1)$ is not on it.
  • A line union a plane in $\mathbb{R}^3$. Scaling stays inside, but adding a vector on the line to a vector on the plane can leave both.

Where vector spaces sit in a first course

In MIT OpenCourseWare's 18.06 Linear Algebra, Gilbert Strang reaches vector spaces and subspaces in Lecture 5, right after elimination and factorizations, and the course description calls them central to linear algebra. The order makes sense: once you can row reduce, the next questions are about which vectors you can reach (column space), which inputs map to zero (null space), and how many directions a space really has. Those questions lead to linear independence, bases, dimension and the rank nullity theorem.

Common mistakes

  • Forgetting the zero vector. Check it first. Any set that misses $\mathbf{0}$ is not a subspace, and this settles many exam questions in one line.
  • Checking only one example. Closure has to hold for all vectors and all scalars. One pair that works proves nothing; one pair that fails proves the set is not a subspace.
  • Forgetting negative scalars. Sets defined by inequalities, such as the first quadrant, usually fail when you multiply by $-1$.
  • Thinking vectors must be arrows or lists. Polynomials, matrices and functions count, as long as the operations satisfy the conditions.
  • Calling any subset a subspace. A subset is any collection of vectors. A subspace is a subset that also passes the three checks.

Common questions

What is a vector space in simple terms?

A vector space is a set of objects that you can add and multiply by numbers, where the results always stay in the set and the usual rules of arithmetic hold. Arrows in the plane, lists of numbers, polynomials, matrices and functions are all examples.

How many axioms does a vector space have?

The standard definition lists ten conditions: closure under addition and scalar multiplication, commutativity and associativity of addition, a zero vector, additive inverses, two distributive laws, associativity of scalar multiplication, and multiplication by 1 leaving a vector unchanged.

How do you check whether a set is a subspace?

Inside a known vector space such as R^n, check three things: the zero vector is in the set, the sum of any two members is in the set, and every scalar multiple of a member is in the set. If any one fails, it is not a subspace.

Are polynomials vectors?

Yes. Polynomials of degree at most 3 form a vector space under ordinary polynomial addition and scaling, and it behaves like R^4 once each polynomial is matched with its list of four coefficients.
